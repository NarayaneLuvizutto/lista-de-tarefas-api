# Automacao de front-end

Projeto base para automacao de testes end-to-end com Cypress.

## Comandos

```bash
npm run cy:open
npm run cy:run
npm run cy:verify
```

## Organizacao

- `e2e/`: cenarios de teste Cypress.
- `fixtures/`: massas de dados usadas pelos cenarios.
- `support/`: configuracoes, comandos customizados e hooks globais.

Nenhum cenario foi criado nesta configuracao inicial.
